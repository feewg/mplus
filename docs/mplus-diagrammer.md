# Mplus Diagrammer

**Version 1**  
**September 2012**

---

## 概述

Mplus Diagrammer 可用于：
- 绘制输入图（input diagram）
- 查看从分析创建的图
- 查看使用输入（无分析）创建的图

在版本1中，图可用于 Mplus 用户指南第3、5和6章中指定的模型类型。图以及相应的输入文件可以保存供将来使用。图可以保存为 PDF 用于发表。

---

## 输入图（Input Diagram）

Diagrammer 使用一组绘图工具来绘制图。Diagrammer 通过 Mplus 编辑器中 **Diagram** 菜单的 **Open Diagrammer** 菜单选项访问。

### 绘图工具

打开 Diagrammer 后，可以使用工具栏、菜单和弹出菜单访问的绘图工具来绘制输入图。

可用的工具栏按钮和菜单项包括：

| 工具 | 功能 |
|------|------|
| Move tool | 移动工具 |
| Draw square | 绘制正方形（观测变量） |
| Draw circle | 绘制圆形（潜变量） |
| Draw factor model | 绘制因子模型 |
| Draw growth model | 绘制增长模型 |
| Draw path | 绘制路径/箭头 |
| Draw covariance | 绘制协方差 |
| Draw residual | 绘制残差 |
| Add caption | 添加标题 |

### 绘制因子模型

要绘制因子模型的图：

1. 点击 **Draw factor model** 按钮或从 **Diagram** 菜单选择 **Draw factor model**
2. 点击打开的页面
3. 将出现提示询问观测变量的数量
4. 接着提示询问是否使用默认变量名或输入变量名
5. 如果选择 **Enter variable names** 提示：
   - 首先提示输入因子名称
   - 然后提示输入观测变量的名称

可以通过再次点击页面添加第二个因子模型。

### 移动因子模型

要移动因子模型：

1. 右键点击因子圆圈或任何因子指标方块
2. 选择 **Select factor/growth model**
3. 这将激活 Move 工具
4. 点击页面上要放置因子模型的位置，或拖动到该位置

要取消选择因子模型，右键点击页面上的任何位置并选择 **Deselect all**。

### 添加观测变量

可以通过以下方式向模型添加观测变量：
- 点击 **Draw square** 按钮，或
- 从 **Diagram** 菜单选择 **Draw square**

### 绘制路径/箭头

可以使用箭头将因子连接到观测变量：

1. 点击 **Draw path** 按钮，或从 **Diagram** 菜单选择 **Draw path**
2. 点击箭头起始的对象
3. 将箭头头部拖动到箭头结束的对象
4. 点击该对象

### 弹出菜单

除了绘图工具外，还提供弹出菜单。右键点击图中的对象或空白区域会显示所有可用选项的弹出菜单。

### 自动生成 MODEL 命令

在屏幕左侧绘制图的同时，**MODEL** 命令正在屏幕右侧编写。当输入图完成后，可以将 Mplus 语言的其余部分添加到屏幕右侧。

### 运行分析

可以通过点击 **RUN** 按钮运行分析。将创建一个带有 `.dgm` 扩展名的文件，其中包含该图。

### 导出为 PDF

可以使用 **FILE** 菜单的 **Export to PDF** 选项将图保存为 PDF。

### 编辑输入图

要在打开图后对其进行更改：

1. 点击 **Diagram** 菜单的 **Input mode** 菜单项
2. 此选项将图从输出图切换为输入图，可以在其中对图进行更改
3. 输入文件显示在屏幕右侧

### 保存输入图

在分析之前，可以使用 **File** 菜单的 **Save** 选项保存图和输入文件。该文件具有 `.mdg` 扩展名，包含图和输入文件。

## 输出图（Output Diagram）

Diagrammer 可用于查看从分析创建的图。这是默认设置。有关其他选择，请参阅 Mplus 编辑器中的 Mplus 菜单。

### 查看输出图

要使用 Diagrammer 查看图：

1. 在 Mplus 编辑器中打开输入文件
2. 点击 **RUN** 按钮
3. 分析完成后，可以使用 **Diagram** 菜单的 **View diagram** 菜单项查看输出图

### 编辑输出图

可以使用上述绘图工具编辑图。参数估计值和标准误默认打印在图上。**View** 菜单显示用于更改图上打印内容的菜单项。

要编辑图：

1. 从 **Diagram** 菜单选择 **Input mode**
2. 然后选择任何绘图工具，例如 **Draw path**，来更改图
3. 当对图进行更改时，输入文件也会进行相应的更改

### 显示参数标签

如果模型包含参数标签，可以通过从 **View** 菜单选择 **Show parameter labels** 将它们添加到图中。

### 添加标题

可以使用 **Add caption** 按钮或菜单项向图添加标题。

### 更新参数估计

更改图后，转到输入文件并点击 **RUN** 按钮以获取带有新参数估计值和标准误的图。

### 文件保存

将创建一个带有 `.dgm` 扩展名的文件，其中包含图和输入文件。也可以使用 **FILE** 菜单的 **Export to PDF** 选项将图保存为 PDF。

### 后续编辑

要在打开图后对其进行更改：

1. 点击 **Diagram** 菜单的 **Input mode** 菜单项
2. 此选项将图从输出图切换为输入图，可以在其中对图进行更改
3. 右侧窗口显示输入文件

## 从输入创建图（Diagram From Input）

Diagrammer 可用于查看使用输入（无分析）创建的图，可以有数据或无数据。

### 无分析创建图

1. 在编辑器中打开输入文件
2. 转到 **Mplus** 菜单
3. 选择 **Get diagram without analysis (data)** 或 **Get diagram without analysis (no data)**
4. 然后点击 **RUN** 按钮
5. 处理输入后，可以使用 **Diagram** 菜单的 **View diagram** 菜单项查看图

### 更改图

可以通过两种方式更改图：

**方式一：修改输入文件**
1. 在 Mplus 编辑器中打开输入文件
2. 对输入进行更改
3. 处理输入

**方式二：直接编辑图**
1. 使用上述绘图工具编辑图
2. 要编辑图，从 **Diagram** 菜单选择 **Input mode**
3. 然后选择任何绘图工具，例如箭头，来更改图

### 显示参数标签

如果模型包含参数标签，可以通过从 **View** 菜单选择 **Show parameter labels** 将它们添加到图中。

### 添加标题

可以使用 **Add caption** 按钮或菜单项向图添加标题。

### 保存更改

更改图后，使用 **File** 菜单的 **Save** 选项将图保存为 `.mdg` 扩展名。

---

## 文件扩展名总结

| 扩展名 | 内容 | 用途 |
|--------|------|------|
| `.dgm` | 图 | 自动创建的图文件 |
| `.mdg` | 图 + 输入文件 | 保存的图和输入文件组合 |
| `.pdf` | 图 | 用于发表的PDF格式 |

---

## 支持的模型类型

版本1支持以下 Mplus 用户指南章节中指定的模型类型：

- **第3章**：回归和路径分析
- **第5章**：验证性因子分析和结构方程模型
- **第6章**：增长模型、生存分析和时间序列
