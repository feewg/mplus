# Mplus Version 8.5 语言附录

本附录描述了 Version 8.5 中引入的更改，包括自 2019 年 11 月发布 Version 8.4 以来发现的小问题修正，以及以下新功能：

- 混合模型潜在类别的自动重新排序
- 使用 Logit 链接对计数、名义和二元变量进行贝叶斯估计，适用于单层、双层和具有单个分类潜在变量的混合模型的实际数据分析和蒙特卡罗模拟研究
- 对观测变量进行分类潜在变量回归的混合模型的贝叶斯估计
- 使用 Logit 链接对计数、名义和二元变量进行数据插补
- 多级数据保存

---

## 自动重新排序混合模型的潜在类别

OUTPUT 命令的 `SVALUES` 选项已扩展，除了使用估计值作为起始值创建 MODEL 命令的输入语句外，还允许对混合模型的潜在类别进行自动重新排序。这适用于具有一个或多个分类潜在变量的模型，只要每个类别具有相同的参数集，例如 LCA 和 LTA 的测量参数。重新排序不适用于 `KNOWNCLASS` 变量。

在此扩展中，`SVALUES` 选项与 ANALYSIS 命令的 `OPTSEED` 选项结合使用。`OPTSEED` 选项用于指定给出原始分析最佳对数似然的 optseed，以便对其类别进行重新排序。

对于具有一个分类潜在变量和三个类别的估计模型，`SVALUES` 选项指定如下，用于将类别从 1 2 3 重新排序为 3 2 1 的三类模型：

```mplus
SVALUES (3 2 1);
```

对于具有三个分类变量（每个变量有四个类别）的模型，`SVALUES` 选项为三个分类潜在变量指定如下：

```mplus
SVALUES (4 1 2 3 | 3 4 1 2 | 2 1 4 3);
```

括号中的数字集按照 VARIABLE 命令的 CLASSES 选项中指定的分类潜在变量的顺序给出。

## 使用 Logit 链接对计数、名义和二元变量进行贝叶斯估计

贝叶斯估计可用于使用 Logit 链接的计数、名义和二元变量，适用于单层、双层和具有单个分类潜在变量的混合模型的实际数据分析和蒙特卡罗模拟研究。

### 实际数据分析 - 计数变量

COUNT 选项用于指定哪些因变量在模型及其估计中被视为计数变量，以及要估计的模型类型。对于计数变量和贝叶斯估计器，可以估计以下模型：泊松（Poisson）和负二项（negative binomial）。负二项模型可以使用 NB-2 方差表示（Hilbe, 2011, p. 63）或 Polya-Gamma 表示（Polson et al., 2013）。只有 Polya-Gamma 表示可用于具有等式约束的模型。计数变量不能具有负值或非整数值。

泊松模型的 COUNT 选项可以用两种方式指定：

```mplus
COUNT = u1 u2 u3 u4;
```

或

```mplus
COUNT = u1 (p) u2 (p) u3 (p) u4 (p);
```

或使用列表功能：

```mplus
COUNT = u1-u4 (p);
```

以下是使用 NB-2 方差表示的负二项模型的 COUNT 选项规范：

```mplus
COUNT = u1 (nb) u2 (nb) u3 (nb) u4 (nb);
```

或使用列表功能：

```mplus
COUNT = u1-u4 (nb);
```

以下是使用 Polya-Gamma 表示的负二项模型的 COUNT 选项规范：

```mplus
COUNT = u1 (nbpg) u2 (nbpg) u3 (nbpg) u4 (nbpg);
```

或使用列表功能：

```mplus
COUNT = u1-u4 (nbpg);
```

对于负二项模型，将估计一个离散参数。离散参数通过使用计数变量的名称来引用。如果离散参数估计为零，则该模型为泊松模型。

### 实际数据分析 - 名义变量

NOMINAL 选项用于指定哪些因变量在模型及其估计中被视为无序分类（名义）变量。无序分类因变量不能有超过 10 个类别。类别数量由数据确定。NOMINAL 选项指定如下：

```mplus
NOMINAL ARE u1 u2 u3 u4;
```

其中 u1、u2、u3、u4 是分析中的无序分类因变量。

对于名义因变量，可以引用除最后一个类别之外的所有类别。最后一个类别是参考类别。在 MODEL 命令中，通过在变量名后添加井号（#）和数字来引用类别。四类别名义变量的三个类别分别引用为 u1#1、u1#2 和 u1#3。

无序分类因变量的模型估计使用零表示最低类别，一表示次低类别，二表示第三低类别，依此类推。如果变量在数据中未以此方式编码，则将自动重新编码。当数据被保存用于后续分析时，将保存重新编码的类别。

### 实际数据分析 - 二元分类 Logit

CATEGORICAL 选项用于指定哪些因变量在模型及其估计中被视为二元或有序分类（序数）变量，以及要估计的模型类型。

对于贝叶斯和二元因变量，默认是 probit 模型。ANALYSIS 命令的 LINK 选项用于通过指定以下内容来请求 logistic 模型：

```mplus
LINK = LOGIT;
```

对于贝叶斯和二元及序数因变量的组合，默认是 probit 模型。序数因变量不可用 logistic 模型。要获得二元变量的 logistic 回归系数和序数变量的 probit 回归系数，请在 ANALYSIS 命令中指定以下内容：

```mplus
LINK = LOGIT PROBIT;
```

对于分类因变量，阈值数量等于类别数减一。在 MODEL 命令中，通过在变量名后添加美元符号（$）和数字来引用阈值。二元变量 u1 的阈值引用为 u1$1。三类别变量 u2 的两个阈值引用为 u2$1 和 u2$2。有序分类因变量不能有超过 10 个类别。类别数量由数据确定。

二元或有序分类因变量的模型估计使用零表示最低类别，一表示次低类别，二表示第三低类别，依此类推。如果变量在数据中未以此方式编码，则将自动重新编码。当数据被保存用于后续分析时，将保存重新编码的类别。

## Monte Carlo 模拟研究

对于贝叶斯，可以为以下模型生成计数变量：泊松、具有 NB-2 方差表示的负二项，以及具有 Polya-Gamma 表示的负二项。变量名后的括号中的字母 c 或 p 表示使用泊松模型生成该变量。变量名后的括号中的字母 nb 表示使用具有 NB-2 表示的负二项模型生成该变量。变量名后的括号中的字母 nbpg 表示使用具有 Polya-Gamma 表示的负二项模型生成该变量。

对于无序分类（名义）变量，在变量名后的括号中放置字母 n，后跟截距数量。截距数量等于类别数减一，因为截距在最后一个类别（参考类别）中固定为零。

对于贝叶斯，可以为 probit 模型生成二元和有序分类（序数）变量。二元变量也可以为 logistic 模型生成。对于二元和有序分类（序数）变量，变量名后的括号中的阈值数量后跟字母 p 指定将使用 probit 模型。如果未指定字母，则使用 probit 模型。阈值数量等于类别数减一。对于二元变量，变量名后的括号中的阈值数量后跟字母 l 指定将使用 logistic 模型。

GENERATE 选项指定如下：

```mplus
GENERATE = u1-u2 (p) u3 (nb) u4 (nbpg) u5 (n 2) u6 (1 l);
```

其中变量名或变量名列表后的括号中的信息定义了数据生成的因变量尺度。在此示例中，变量 u1 和 u2 是使用泊松模型生成的计数变量。变量 u3 是使用具有 NB-2 表示的负二项模型生成的计数变量。变量 u4 是使用具有 Polya-Gamma 表示的负二项模型生成的计数变量。泊松模型和具有 NB-2 表示的负二项模型的计数变量可以单独或一起生成。具有 Polya-Gamma 表示的负二项模型的计数变量不能与其他计数模型一起生成。变量 u5 是具有两个截距的三类别无序分类（名义）变量。变量 u6 是使用 logistic 模型生成的具有一个阈值的二元变量。

## 使用 Logit 链接对计数、名义和二元变量进行数据插补

DATA IMPUTATION 命令已扩展，包括使用 Logit 链接对计数、名义和二元变量进行插补。这仅允许在使用 ESTIMATOR=BAYES 的 H0 插补（MODEL 命令）中使用。

要指定被插补的变量是计数变量，在 IMPUTE 列表中的变量名后的括号中包含字母 ct。要指定被插补的变量是名义变量，在 IMPUTE 列表中的变量名后的括号中包含字母 n。要指定被插补的变量是具有 Logit 链接的二元变量，在 IMPUTE 列表中的变量名后的括号中包含字母 c，并且必须在 ANALYSIS 命令中包含 LINK=LOGIT。

```mplus
IMPUTE = u1 (ct) u2 (ct) u3 (n) u4 (n) u5 (c);
```

指定当使用 LINK=LOGIT 时，u1 和 u2 将作为计数变量进行插补，u3 和 u4 将作为名义变量进行插补，u5 将作为具有 Logit 链接的分类变量进行插补。

## 多级数据保存和绘图

SAVEDATA 命令可以与 TYPE=TWOLEVEL、TYPE=THREELEVEL 和 TYPE=CROSSCLASSIFIED 结合使用，以保存层间因子和随机潜在变量、BETWEEN 列表上指定的层间观测变量，以及 AUXILIARY 列表上指定的层间辅助变量，保存在可以使用 TYPE=IMPUTATION 分析的单独数据集中。

对于 TYPE=TWOLEVEL 和 TYPE=THREELEVEL，保存最高层的变量。对于 TYPE=CROSSCLASSIFIED，保存 2b 层的变量。要获取这些数据集，请指定以下内容：

```mplus
SAVEDATA:
FILE = save*.dat;
SAVE = FSCORES (200 10);
```

其中文件名后的星号（*）表示将保存单独的数据集。保存的数据集名称将是文件名后跟数据集编号。SAVE 选项指定将保存这些变量的因子分数。括号中的 200 指定将保存 200 个插补数据集。括号中的 10 指定稀释为 10。

当数据集在 TYPE=IMPUTATION 中使用时，DATA 命令的 FILE 选项中指定的数据文件名为 savelist.dat。有关如何使用 TYPE=IMPUTATION 的示例，请参见 Mplus 用户指南中的示例 13.13。
