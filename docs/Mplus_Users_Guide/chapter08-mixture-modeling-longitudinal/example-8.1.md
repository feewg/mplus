# EXAMPLE 8.1: GMM for a continuous outcome using automatic starting values and random starts

## Description
这个例子展示了如何使用自动起始值和随机起始值来估计连续结果的增长混合模型（Growth Mixture Model, GMM）。GMM是一种纵向数据的混合模型，其中潜类别变量c表示不同的增长轨迹类别。该模型允许在类别内存在个体差异，通过随机效应（连续潜变量）来表示。

## Mplus Input
```mplus
TITLE: this is an example of a GMM for a
continuous outcome using automatic
starting values and random starts
DATA: FILE IS ex8.1.dat;
VARIABLE: NAMES ARE y1–y4 x;
CLASSES = c (2);
ANALYSIS: TYPE = MIXTURE;
STARTS = 40 8;
MODEL:
%OVERALL%
i s | y1@0 y2@1 y3@2 y4@3;
i s ON x;
c ON x;
OUTPUT: TECH1 TECH8;
```

## Explanation
在这个例子中，估计了连续结果的增长混合模型（GMM）。因为c是分类潜变量，所以图的解释与连续潜变量的模型不同。从c到增长因子i和s的箭头表示增长因子在x上的回归截距随c的类别而变化。这对应于i和s在代表c类别的虚拟变量集上的回归。从x到c的箭头表示c在x上的多项logistic回归。

**TITLE命令**：用于为分析提供标题，标题在输出中打印在分析摘要之前。

**DATA命令**：用于提供关于要分析的数据集的信息。FILE选项用于指定包含要分析数据的文件名ex8.1.dat。由于数据集是自由格式，不需要FORMAT语句。

**VARIABLE命令**：用于提供关于数据集中变量的信息。NAMES选项用于为数据集中的变量分配名称。本例中的数据集包含五个变量：y1、y2、y3、y4和x。注意，连字符可以用作便利功能来生成名称列表。CLASSES选项用于为模型中的分类潜变量分配名称，并指定每个分类潜变量的潜类别数。在上例中，有一个分类潜变量c，它有两个潜类别。

**ANALYSIS命令**：用于描述分析的技术细节。TYPE选项用于描述要执行的分析类型。通过选择MIXTURE，将估计混合模型。

当指定TYPE=MIXTURE时，使用用户指定或自动起始值来创建模型中所有参数（除方差和协方差外）的随机扰动起始值集。在本例中，随机扰动基于自动起始值。最大似然优化分两个阶段进行。在初始阶段，生成20组随机起始值。使用每组随机起始值进行10次迭代的优化。以最高对数似然的4次优化的结束值作为最终阶段优化的起始值，使用TYPE=MIXTURE的默认优化设置进行。可以使用ANALYSIS命令的STARTS和STITERATIONS选项进行更彻底的多解调查。在本例中，使用40组初始阶段随机起始值，并进行8次最终阶段优化。

**MODEL命令**：用于描述要估计的模型。对于混合模型，有一个由标签%OVERALL%指定的总体模型。总体模型描述对所有潜类别通用的模型部分。|符号用于在增长模型中命名和定义截距和斜率增长因子。|符号左侧的名称i和s分别是截距和斜率增长因子的名称。|符号右侧的语句指定增长模型的结果和时间分数。斜率增长因子的时间分数固定为0、1、2和3，以定义等距时间点的线性增长模型。时间点在斜率增长因子上的零时间分数将截距增长因子定义为初始状态因子。作为增长模型参数化的一部分，截距增长因子的系数固定为1。结果变量的残差方差被估计，允许在不同时间不同，且残差不相关作为默认值。

在所示的增长模型参数化中，四个时间点的结果变量的截距默认固定为零。增长因子的截距和残差方差默认被估计，增长因子残差协方差默认被估计，因为增长因子不影响模型中除其自身指标外的任何变量。增长因子的截距默认不跨类别相等。增长因子的残差方差和残差协方差默认跨类别相等。

第一个ON语句描述截距和斜率增长因子在协变量x上的线性回归。第二个ON语句描述分类潜变量c在协变量x上的多项logistic回归（比较类别1和类别2）。此回归的截距默认被估计。此类分析的默认估计量是带稳健标准误的最大似然。可以使用ANALYSIS命令的ESTIMATOR选项选择不同的估计量。

以下是c在协变量x上的多项logistic回归的替代规范：
```
c#1 ON x;
```
其中c#1指c的第一个类别。通过向分类潜变量的名称添加井号(#)后跟类别号来引用分类潜变量的类别。这种替代规范允许在MODEL命令中引用单个参数以给出起始值或放置限制。

**OUTPUT命令**：用于请求默认未包含的额外输出。TECH1选项用于请求包含模型中所有自由参数的参数规范和起始值的数组。TECH8选项用于请求在输出中打印估计模型的优化历史。TECH8默认在计算期间打印到屏幕。TECH8屏幕打印有助于确定分析所需的时间。
