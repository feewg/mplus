# EXAMPLE 8.7: A sequential process GMM for continuous outcomes with two categorical latent variables

## Description
这个例子展示了连续结果的序贯过程增长混合模型（sequential process GMM）。该模型包含两个分类潜变量c1和c2，第二个过程的潜类别与第一个过程的潜类别相关。这是一种潜在转换分析（latent transition analysis, LTA）的类型。

## Mplus Input
```mplus
TITLE: this is an example of a sequential
process GMM for continuous outcomes with
two categorical latent variables
DATA: FILE IS ex8.7.dat;
VARIABLE: NAMES ARE y1-y8;
CLASSES = c1 (3) c2 (2);
ANALYSIS: TYPE = MIXTURE;
MODEL:
%OVERALL%
i1 s1 | y1@0 y2@1 y3@2 y4@3;
i2 s2 | y5@0 y6@1 y7@2 y8@3;
c2 ON c1;
MODEL c1:
%c1#1%
[i1 s1];
%c1#2%
[i1*1 s1];
%c1#3%
[i1*2 s1];
MODEL c2:
%c2#1%
[i2 s2];
%c2#2%
[i2*-1 s2];
OUTPUT: TECH1 TECH8;
```

## Explanation
在这个例子中，估计了上图所示的连续结果的序贯过程增长混合模型。第二个过程的潜类别与第一个过程的潜类别相关。这是一种潜在转换分析。潜在转换分析在例8.12、8.13和8.14中展示。

总体模型中的|语句用于命名和定义增长模型中的截距和斜率增长因子。在第一个|语句中，|符号左侧的名称i1和s1分别是截距和斜率增长因子的名称。在第二个|语句中，|符号左侧的名称i2和s2分别是截距和斜率增长因子的名称。在两个|语句中，|符号右侧的值是斜率增长因子的时间分数。对于两个增长过程，斜率增长因子的时间分数固定为0、1、2和3，以定义等距时间点的线性增长模型。时间点在斜率增长因子上的零时间分数将截距增长因子定义为初始状态因子。作为增长模型参数化的一部分，截距增长因子i1和i2的系数固定为1。

在所示的增长模型参数化中，四个时间点的结果变量的均值默认固定为零。截距和斜率增长因子均值默认被估计。增长因子的方差也默认被估计。增长因子默认相关，因为它们是独立（外生）变量。增长因子的均值默认不跨类别相等。增长因子的方差和协方差默认跨类别相等。

总体模型中的ON语句描述从分类潜变量c1的类别转换到分类潜变量c2的类别的概率。ON语句描述c2在c1上的多项logistic回归（比较c2的类别1和类别2）。在此多项logistic回归中，对应于每个分类潜变量的最后一个类别的系数固定为零。具有多个分类潜变量的模型的参数化在第14章中讨论。由于c1有三个类别，c2有两个类别，估计两个回归系数。c1的均值和c2的截距默认被估计。

当存在多个分类潜变量时，每个变量都有自己的MODEL命令。每个潜变量的MODEL命令由MODEL后跟潜变量的名称指定。对于每个分类潜变量，该变量每个类别不同的模型部分由由分类潜变量后跟井号后跟类别号组成的标签指定。在上例中，标签%c1#1%指与总体模型不同的分类潜变量c1的类别一的模型部分。标签%c2#1%指与总体模型不同的分类潜变量c2的类别一的模型部分。每个分类潜变量的类别特定模型部分指定截距和斜率增长因子的均值可在每个类别中自由估计。

以下是c2在c1上的多项logistic回归的替代规范：
```
c2#1 ON c1#1 c1#2;
```
其中c2#1指c2的第一个类别，c1#1指c1的第一个类别，c1#2指c1的第二个类别。通过向分类潜变量的名称添加井号(#)后跟类别号来引用分类潜变量的类别。这种替代规范允许在MODEL命令中引用单个参数以给出起始值或放置限制。
